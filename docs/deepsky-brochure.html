DeepSky ✦

Your command center for GitHub Copilot CLI

A desktop app that wraps the Copilot CLI experience with session management, live status tracking, notifications, and a proper multi-tab terminal.

⬇ Download Latest 🍎 View all releases ⭐ View on GitHub ℹ About & Changelog
Prerequisite: GitHub Copilot CLI installed and authenticated. Windows users can install it with winget install github.copilot.

Features

  • 🗂 Visual sidebar — browse, search, and rename all sessions (active + history)
  • 📂 Session grouping — Edge-style groups with drag-and-drop, colors, collapse/expand, whole-group reorder, and in-place rename that survives live refreshes
  • 🕘 Recent History scope — by default DeepSky shows the last 3 months / 500 sessions, keeps sidebar search metadata-only, and offers a visible Show all history button for the full archive
  • 📁 Working directory — pick a directory per session, change on the fly without dropping the session, persisted across restarts, now shown as an outline-only yellow folder affordance in the Active list
  • ⚡ Live status badges — Working, Waiting, Idle, Pending, Done — updated quickly from substantive agent output without idle redraw flicker
  • 🖥 Multi-tab terminal — 10K scrollback, reliable http(s) link opening, close button on tabs, reliable Ctrl+V paste, first-frame scrolling, and Ctrl+Tab order that mirrors the sidebar
  • 🖱 Terminal selection, focus, and scrolling — click-drag selects terminal text normally, stranded focus recovers on click or typing, Copilot CLI transcripts scroll with the wheel, and copied output strips rendered terminal chrome
  • 🔔 Notifications — toast, badge counter, dropdown panel, native OS alerts
  • 📋 Session Status panel — live intent, summary, next steps, session-scoped files changed, timeline, and related resources from visible conversation mentions. Work Items show type and truncated title with the full text on hover. Toggle with Ctrl+I.
  • 🎨 Catppuccin Mocha & Latte themes
  • 📑 Tab scroll indicators — arrow buttons when tabs overflow the tab bar
  • 🏷 Smart session tagging — auto-detects SQL, databases, and more
  • ⌨ Keyboard shortcuts — Ctrl+N, Ctrl+T, Ctrl+Tab, Ctrl+W, Ctrl+C copy, and more
  • 🔄 Auto-update control — enable or disable update checks; downloaded updates can be installed with Restart now and show visible recovery if the installer does not exit cleanly
  • 🍎 Cross-platform installers — Windows setup packages plus macOS DMG/ZIP artifacts from release CI
  • 🚀 Startup loading screen — clear boot progress while sessions, notifications, and restored tabs initialize
  • 🧭 Agency launcher toggle — optionally start new sessions with agency copilot instead of the default Copilot CLI command
  • ⚙️ Extra Copilot args — one shared setting for new-session launcher arguments, applied to copilot or agency copilot depending on the Agency toggle
  • 🚀 One-off launch options — start a single new session with Copilot or Agency and custom args without changing your global launcher settings
  • 🚦 Starting rows — slow Copilot or Agency launches appear in the Active list immediately while the real session initializes
  • ↩ Closed-tab restore — Ctrl+Shift+T reopens recently closed sessions without losing the restore stack on transient failures
  • 🛠 Copilot CLI compatibility — new sessions discover the CLI-assigned session ID after spawn, and saved History sessions reopen by their stable local UUID
  • ⚙️ Settings tabs — General, Updates, Shortcuts, and About, including the current version and recent release notes
  • 📂 Directory picker — browse for a default working directory with Browse & Clear buttons
  • ✨ Enhance Instructions — one-click rewrite of your global Copilot instructions using the latest context-engineering practices, with timestamped backup and one-click rollback
  • 📄 Files Folder quick action — jump straight to the session's files/ directory from the Session Status summary

About & Changelog

Settings → About
Scrolling, copy, and status are cleaner

The latest polish keeps the CLI transcript scrollable, cleans terminal copy output, and keeps the status timeline focused on prompts and key results.

  • Settings → About shows the installed version and recent release notes.
  • Terminal links open reliably, stranded focus recovers, and Copilot CLI transcript panes respond to mouse wheel events.
  • Copied multiline terminal text drops rendered gutters, tree guides, dividers, timestamps, and scrollbar artifacts.
  • Session Status timelines hide session-resume and plan-update plumbing, keeping prompts and key results.
  • Slow session launches show a temporary Starting row in the Active list.
  • Work Items in Session Status show type and title with full hover text.
  • Settings → About includes quick Email and Teams feedback actions.
  • Download links stay on the GitHub release page instead of being hard-coded into the brochure.
